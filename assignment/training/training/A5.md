# A5: fixed actor, on-policy world-model adaptation

The collector uses the exact A4 120k EMA (`755e95f0…55477ce3`) and the WM
recorded in the actual A4 evaluation. The released Stage 4 data and pretrain WM
are not substitutes. Image encoding, goals, normalizers and actor weights stay
fixed; only `action_encoder`, `predictor` and `pred_proj` learn.

## Prepare and collect

Prepare nonoverlapping development and formal reserved JSON scene lists first.
The plan deterministically reserves 128 official-train scenes for WM training
and another 32 for calibration. Each scene's seeds and branches stay together.
The plan also fixes seeds 0/2/3, anchor probability .25 and ascending scene order.
It provides ample additional scenes in that fixed order; insufficient complete
anchors cause an explicit incomplete-data failure instead of changing the split.

```bash
python scripts/prepare_a5_collection.py \
  --a4-run /path/to/a4-120k --policy checkpoints/actor-120k.pt \
  --world-model checkpoints/original-wm.pt \
  --development-scenes inputs/development-scenes.json \
  --reserved-scenes inputs/reserved-scenes.json --out inputs/collection-plan.json
```

Write the union of `plan.scenes.train` and `plan.scenes.calibration` to
`inputs/collection-scenes.json`, then generate separate training references:

```bash
python -m assignment.training.planning.goals --split train \
  --scene-file inputs/collection-scenes.json --every 80 --workers 8 --gpus 0 \
  --out dataset/reference-goals
python -m assignment.training.data.collect_goal_onpolicy \
  --plan inputs/collection-plan.json --policy checkpoints/actor-120k.pt \
  --world-model checkpoints/original-wm.pt --goals dataset/reference-goals/goals.npz \
  --workers 8 --gpus 0 --out dataset/onpolicy-a5
```

Exactly 5,000 train anchors × 16 candidates and 500 calibration anchors × 32
candidates are collected. Each split has equal numbers of A4-16/A4-32 behavior
anchors. Main trajectories use the original A4 planner. Independent per-anchor
RNGs produce branch candidates without consuming the main policy RNG. Branches
execute all 16 blocks without replanning; actions are clipped before being
normalized again and stored in float32 with actual post-block encoder latents.
Physics failures such as dropped boxes remain valid. Numerical exceptions,
time limits and finalization invalidate the entire candidate set for that anchor.
Physics state, targets, clock, warnings and the full rolling score history are
restored even on exceptions. Wrapper/controller and policy history are untouched.

`manifest.json` locks source, models, goals, scenes and recipe. Shards are atomic.
Each worker saves its completed task receipt; `complete.json` is published only
when every fixed quota is met. `--resume` replays main trajectories deterministically
and skips saved anchors. Incomplete buffers are recollected; complete shards are
preserved. The trainer rejects incomplete datasets, changed shards and mixed scenes.

## Train and select one WM

```bash
python -m assignment.training.training.finetune_goal_onpolicy \
  --data dataset/onpolicy-a5 --init checkpoints/original-wm.pt \
  --policy checkpoints/actor-120k.pt --out checkpoints/wm-a5 \
  --steps 60000 --batch 256 --microbatch 16 --lr 1e-4 --warmup 1000 \
  --eval-every 2000 --state-every 200 --seed 0 \
  --wandb-project 6280_wm --wandb-entity tianzizh-university-of-pennsylvania \
  --wandb-run-id a5-wm-onpolicy-120k-s0
```

AdamW betas are (.9,.999), decay .001, gradient clip 1.0, with warmup/cosine
schedule. The effective batch is 256 complete candidate trajectories; microbatches
are weighted by candidate count. The MSE spans all 16 autoregressive steps and
latent dimensions. Targets are detached; no goal loss or actor optimizer is used.
All image parameters and buffers, other frozen parameters and all BN running
statistics are checked by hashes during training and recovery.

Calibration at step 0 and every 2,000 steps logs h=1/4/8/16 MSE and agreement/regret
for the first 16 and all 32 candidates of the same fixed sets. Predicted and true
costs both use the minimum goal distance over all 16 future latents. Regret uses
the Stage 4 sample standard deviation (`correction=1`) plus 1e-8. The average
of regret_16 and regret_32 selects a shared WM; exact ties retain the earlier
checkpoint, including the original step-0 WM. Task evaluation never selects it.

`train-state.pt` atomically stores model/optimizer/scheduler, sampling and dropout
RNGs, last step and best checkpoint every 200 steps and at calibration. Resume
requires the same source, data, model identities, recipe and GPU model. Immutable
`selected-step-*.pt` files prevent a crash between selection and recovery from
changing the selected model. On completion `model.pt` and `selection.json` publish
the common selected WM; `latest.pt` is the most recently calibrated WM. W&B logs
training/calibration metrics, selected step/hash and frozen checks. Collection
and training costs are recorded separately from online decision timings.

## Evaluate

`GoalActorAgent` and the structured evaluator support `A5-16` and `A5-32`.
Pass the same frozen actor, the selected `model.pt`, and `--wm-selection
checkpoints/wm-a5/selection.json`. The evaluator verifies the receipt and unchanged
image representation. These modes otherwise use the exact A4 scorer and interface.

`--reference-run <completed-a4-120k>` checks model identities, scene/seed coverage,
goals, task, scoring, candidate counts, L40/dtype, workers, videos and library
versions before reusing both same-budget A4 groups. Reports add scene-paired
A5-16−A4-16, A5-32−A4-32 and A5-32−A5-16 comparisons and retain the usual
videos, decisions, counts, censored stage transitions and timing evidence.

Cluster launchers are `scripts/collect_goal_actor_a5.sbatch`,
`scripts/finetune_goal_actor_a5_wm.sbatch` (submit with `afterok:<collection job>`),
and `scripts/evaluate_goal_actor_a5.sbatch`. Set `TASK_ROOT` to the isolated
workspace. Collection/WM training can be queued together; A5 task evaluation is
a separate submission after selection and the A4 reference are complete.

## Verify

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m unittest discover -s tests -p 'test_*a5.py' -v
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m unittest discover -s tests -p 'test_goal*.py' -v
```

Tests exercise real MuJoCo restoration (including bounded history), full-rollout
gradients and uneven microbatches, BN/representation immutability, trajectory-min
ranking, scene isolation, matched references, and exact model recovery after a
deliberate training interruption. Small fixtures verify implementation only.
